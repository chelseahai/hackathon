01 / Drafting rules

  1. Establish the frame

    Locate the reference axes and the body's principal levels.

  2. Place the landmarks

    Translate measured proportions into points.

  3. Construct the curves

    Connect the points through a defined sequence.

  4. Resolve the block

    Bring the lines together as a pattern.

02 / Python translation

body = measurements()

frame = reference_axes(body)
points = place_landmarks(frame)

for rule in drafting_rules:
    points = rule.apply(points)

curves = connect(points)
